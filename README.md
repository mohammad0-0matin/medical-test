**سلامت‌یار (SalamatYar)** یک پلتفرم جامع، امن و هوشمند برای تجمیع، ساختاردهی و پایش پرونده‌های پزشکی، نسخه‌های درمانی و آزمایش‌های دوره‌ای بیماران است. این سیستم با بهره‌گیری از **هوش مصنوعی چندوجهی (Multimodal Vision AI)**، داده‌های غیرساختاریافته برگه‌های آزمایش و نسخ دارویی را به اطلاعات بالینی دقیق، نمودارهای تحلیلی و توصیه‌های شخصی‌سازی‌شده تبدیل می‌کند.

---

## 🌟 امکانات و قابلیت‌های کلیدی

### ۱. 📄 اسکن و ساختاردهی خودکار آزمایشگاه (AI Smart Scan)
- استخراج هوشمند پارامترهای آزمایش (هموگلوبین، قند ناشتا، چربی، ویتامین‌ها و...) از روی عکس یا فایل PDF برگه آزمایش.
- شناسایی خودکار مقادیر، واحدها، بازه‌های نرمال مرجع و تشخیص وضعیت‌های غیرطبیعی (Low / High).
- قابلیت ویرایش، دسته‌بندی و پیوست فایل‌های مبدأ جهت استناد پزشکی.

### ۲. 🩺 ماژول مدیریت نسخه‌های پزشک (Prescription Management)
- ثبت و مدیریت نسخه‌های تجویزشده توسط پزشکان داخل یا خارج سامانه.
- **استخراج هوشمند اقلام دارویی از نسخه کاغذی** با بینایی ماشین.
- چاپ برگه رسمی نسخه استاندارد سلامت‌یار (A4) با وضوح بالا، تایپوگرافی خوانا، کد پیگیری و کادر مهر پزشک/داروخانه.
- قابلیت تنظیم سریع یادآور مصرف به ازای هر قلم دارو تنها با یک کلیک.

### ۳. 🤖 دستیار سلامت هوشمند (Context-Aware AI Health Advisor)
- تحلیل تعاملی و برخط پرونده بالینی توسط مدل‌های پیشرفته زبانی.
- پاسخ‌گویی به سؤالات بیمار بر اساس داده‌های آزمایش‌ها، داروها و سوابق پزشکی ثبت‌شده در حساب کاربری.
- ارائه توصیه‌های مراقبتی، تغذیه‌ای و نکات تکمیلی با رعایت اصول ایمنی سلامت.

### ۴. 🪪 کارت سلامت و گذر دسترسی اضطراری (Health Card & Emergency Pass)
- شناسنامه بالینی فشرده شامل گروه خونی، سوابق بیماری‌های خاص، حساسیت‌های دارویی و مخاطبین اضطراری.
- صدور **گذر دسترسی اضطراری پزشک (Emergency QR Pass)** با زمان اعتبار محدود و بدون وابستگی به اینترنت، مناسب شرایط اورژانسی.
- پرینت رسمی و گزارش جامع پزشکی منطبق بر استانداردهای گزارش‌دهی بالینی.

### ۵. ⏰ سیستم یادآورهای هوشمند بالینی (Clinical Reminders)
- تنظیم و ثبت یادآورهای مصرف داروها و موعد آزمایش‌ها یا چکاپ‌های دوره‌ای.
- ذخیره‌سازی ابری و دیتابیسی یادآورها (عدم از دست رفتن اطلاعات با پاک‌شدن حافظه مرورگر).
- تفکیک وضعیت‌های «امروز»، «آینده» و «انجام‌شده» در پیشخوان اختصاصی.

### ۶. 👥 گردش کار تأیید و ایمنی داده‌ها (Approval Workflow & RBAC)
- تفکیک نقش‌های دسترسی پزشک، کاربر و بیمار با ایزولاسیون کامل حریم خصوصی.
- جریان تأیید آزمایش‌های افراد تحت تکفل: امکان ثبت توسط پزشک و نمایش در کارتابل بررسی بیمار قبل از ورود قطعی به پرونده.
- امکان مشاهده نام و هویت ثبت‌کننده در کنار هر رکورد آزمایشگاهی.

### ۷. 📈 پایش روند فاکتورها (Trends & Analytics)
- نمودارهای خطی مقایسه‌ای برای رهگیری نوسانات فاکتورهای آزمایشگاهی در طول زمان.
- فیلتر هوشمند بر اساس نوع آزمایش، تاریخ، و برچسب‌های بالینی.

### ۸. 🧭 تور راهنمای تعاملی (Interactive Onboarding)
- راهنمای گام‌به‌گام برای کاربران جدید به منظور آشنایی سریع با تمامی بخش‌های سامانه با حفظ وضعیت در پایگاه داده.

## 🚀 راهنمای نصب و راه‌اندازی سریع

### پیش‌نیازها
- پایتون نسخه `3.11` یا بالاتر
- نودجی‌اس نسخه `18` یا بالاتر (`Node.js & npm`)
- ابزار `Git`

---

### ۱. کلون کردن مخزن
```bash
git clone https://github.com/mohammad0-0matin/medical-test.git
cd medical-test
```

---

### ۲. راه‌اندازی بک‌اند (Django API)

1. ایجاد محیط مجازی پایتون و فعال‌سازی آن:
   ```bash
   # ویندوز (PowerShell):
   python -m venv venv
   .\venv\Scripts\Activate.ps1

   # لینوکس یا مک:
   python3 -m venv venv
   source venv/bin/activate
   ```

2. نصب کتابخانه‌ها و بسته‌های موردنیاز:
   ```bash
   pip install -r requirements.txt
   ```

3. تنظیم متغیرهای محیطی:
   یک فایل با نام `.env` در مسیر ریشه پروژه ایجاد کرده و کلیدهای مورد نیاز را قرار دهید:
   ```env
   SECRET_KEY=your_django_secret_key_here
   DEBUG=True
   AI_API_KEY=your_google_gemini_api_key_here
   AI_BASE_URL=https://generativelanguage.googleapis.com
   ```

4. اعمال مایگریشن‌های دیتابیس و اجرای سرور:
   ```bash
   python manage.py migrate
   python manage.py runserver
   ```
   *سرویس بک‌اند روی نشانی `http://127.0.0.1:8000` در دسترس خواهد بود.*

---

### ۳. راه‌اندازی فرانت‌اند (React + Vite)

در یک پنجره ترمینال جداگانه، دستورات زیر را اجرا کنید:

```bash
# ورود به پوشه فرانت‌اند
cd medical-frontend

# نصب پکیج‌های npm
npm install

# اجرای سرور توسعه فرانت‌اند
npm run dev
```
*رابط کاربری سامانه به طور پیش‌فرض روی نشانی `http://localhost:5173` اجرا می‌شود.*

## 🔒 اصول حریم خصوصی و امنیت داده‌های پزشکی

در سلامت‌یار امنیت اطلاعات بیمار در اولویت اول قرار دارد:
- **ایزولاسیون کامل داده‌ها:** دسترسی به پرونده بیماران منوط به اعتبارسنجی سطح شیء (Object-Level Permissions) است و پزشک تنها به بیماران متصل به خود دسترسی دارد.
- **عدم افشای اطلاعات حساس:** اطلاعاتی نظیر کد ملی، آدرس یا تاریخچه کامل در لیست‌های عمومی فاش نمی‌شود.
- **حذف نرم (Soft Delete):** سوابق و آزمایش‌های پزشکی به منظور حفظ یکپارچگی تاریخی پرونده حذف فیزیکی نمی‌شوند.
- **ارقام لاتین (Latin Digits):** جهت جلوگیری از هرگونه خطای تفسیری در مقادیر بالینی و کد داروها، اعداد به صورت استاندارد بین‌المللی نمایش داده می‌شوند.
